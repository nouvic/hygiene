## Unscored rules

A rule with no cases in this corpus is not scored, and its row above reads
`-` for precision and recall. Today:
- `HYG-PHA-003` (phantom-reference)
- `HYG-HIS-001` (history-residue)

Why each of them is unscored, so that the reason cannot outlive the rule:

- `HYG-PHA-003` needs a symbolic link, and a corpus copied into a temporary
directory cannot carry one: the copy dereferences it or drops it.

- `HYG-HIS-001` needs Git history with a deleted document, and this corpus
is a plain tree.

The conditions these rules read are exercised by `./test/run`; this benchmark
does not score them.

## What these numbers do not say

The corpus is a set of clear archetypes, one per family per case. It is not a
random sample of real repositories, so recall here is an upper bound and not
an estimate of what the detector finds in the field. Precision is the number
the gate is set on, because a false positive is what makes a scanner get
uninstalled.
